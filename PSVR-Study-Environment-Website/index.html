PSVR-Study-Environment

PSVR has no study environments of its own, so this generator builds one: it takes a 360 video to serve as the room and an ordinary video of study material, and produces a single mp4 with the study video sitting in the middle of the 360 scene, ready to copy to a USB stick and play in the PSVR media player with the VR option ticked, where it can be paused and rewound. A room you wear, with the lesson held at the centre of vision.

Open the repository

1

What you bring

Two named files, in one folder with the script:

  • vr.mp4: the 360 environment video.
  • non360.mp4: the ordinary video of study material.

Requirements: Bash, and ffmpeg with ffprobe on the path. The script itself is study-generate.sh.

2

The run itself

chmod +x study-generate.sh
./study-generate.sh

Called with no arguments, the script uses the default names above and writes output.mp4 in the same folder. Up to three positional arguments override the names in the order background, overlay, output. Running it with --help prints the usage. The script has no menu.

3

What happens inside the one ffmpeg pass

  1. Both inputs are checked for existence and probed with ffprobe for corruption. Either fault stops the run with exit code 1 before any conversion.
  2. The overlay is scaled to 640 by 360 and placed at the centre of the 360 video.
  3. The result is scaled to 1920 by 1080 at 60 frames per second, H.264 baseline profile level 4.0 at 4M bitrate, with the background audio copied through when present.
  4. The background loops twice extra and the overlay three times extra, so the output lasts roughly three times the background.

The refusal that matters: naming an input as the output is rejected, because ffmpeg would overwrite a file it is still reading.

4

Limits, stated plainly

This is a study environment, not a workspace, because the material is recorded beforehand and cannot be worked on inside the headset. On the PlayStation side, playback needs h264 above 30 frames per second and under 4 gigabytes per file because of the FAT32 file system.

The test suite runs with python3 -m unittest against test_study_generate.py. For anyone who needs to type, the semi VR alternative is cinematic mode on a PC: a giant theatre screen rather than a 360 environment.
